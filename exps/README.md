Put exploratory experiments here. Create one folder per experiment, named with the
date and the Issue number: e.g. `20261115_issue-42_first_data_exploration`.
Each experiment has an Issue that follows `criteria.md`; the Issue records the
paths of the code and results in this folder.

Jupyter notebook is not recommended. Use [Marimo notebook](https://marimo.io/) instead if possible.  At the same time, try to incorporate as
much code as possible into the library for reusability.

An experiment worth putting in the paper is moved into the main workflow (`workflow/`) by a person, not by an agent.

Large outputs of an experiment go to `data/exps/<same folder name>/` (no person's name in the path). If the folder name already exists, add `-2`, `-3`, ... See the main README for the full rules.
